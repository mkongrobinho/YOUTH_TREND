# YouthTrend Campus Social Platform 🚀

> A platform that permits students of different universities to communicate, share related content, and exchange ideas and information.

---

## 📌 Features

* **Inter-Campus Communication:** Connects students across different universities in a single digital space.
* **Content Sharing:** Share updates, academic insights, campus life posts, and GIST.
* **Student Feed:** Stay updated with real-time posts and interactions from peers.

---

## 🛠️ Tech Stack

### Frontend (`youthtrend-frontend`)
* **Framework / Library:** React
* **Styling:** Tailwind CSS
* **Design:** Figma

### Backend (`backend`)
* **Server / API:** Node.js / Express
* **Database & Services:** PostgreSQL / Supabase
* **Version Control:** Git & GitHub
